# fraud-detection-audit.NAU-audit-acca--data-practice
基于CDA2级思路及框架及伊利诺伊大学香槟分校理论逻辑(coursera攻读)的内部审计数据分析实践--以信用卡欺诈风险识别为列
南京审计大学大一学生于acca基础阶段及CDA数据分析师认证2级备考期间完成项目.基于CDA2级的审计数据分析实战项目,包含EDA，WOE分箱，逻辑回归等初步尝试，并利用coursera平台攻读伊利诺伊大学香槟分校(University of lllinois Uvbana-Champaign)相关课程进行嵌入优化完成.
数据集来源于kaggle公开已去敏数据集(Credit Card Fraud Detection)，数据集URL:https://www.kaggle.com/datasets/kaushalnandania/credit-card-fraud-detection，相关算法及逻辑思路借鉴嵌入伊利诺伊大学香槟分校(University of lllinois Uvbana-Champaign)课程:审计|:审计概念基础+审计||:审计实务和Foundations of strategy internal auditing(战略内部审计基础)作为审计专业理论基础以及UIUC该校会计数据分析专项课程作为会计技术性改进思路  
结合CDA数据分析思路框架及技术栈制作项目基本框架，和UIUC审计等相关课程知识点相关嵌入,希望体现个人作为ACCA方向班的国际化思维，结合CDA数字化技能，致力于智能审计及大数据审计发展方向，体现个人大一的成长轨迹。
